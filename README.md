# Climb To The Top
You play as a new member of the larpusk server and you want to reach the top of the leaderboards of this dying server while bribing the mods with the emeralds you earn
made for the marcusk gamejam

# Setup Instructions (Windows Only):
Itch.io Installation: Unzip the folder and run the .exe file link to the project: https://iforgor09.itch.io/climb-to-the-top
Github Installation:
- Pull from this repository
- Install Godot 4.7.2 (or the latest version) from the official website: https://godotengine.org/download/windows/
- Extract the .exe file and run it
- Click import project and select the folder containing all the source files
# Features:
- Shop System
- Levelling System
- Handmade Sprites and NO AI WHATSOEVER
